Datos del proyecto

Nombre PadelVision — Sistema de Cámara VAR Automática para Pádel
Integrantes Agustín Kramer y Camilo Yorgovan
Curso 6° Año IVT
Objetivo Ayudar a revisar jugadas dudosas y determinar si la pelota picó dentro o fuera de la cancha.
Problema Algunas jugadas son muy rápidas y difíciles de observar con precisión durante un partido.

Funciones principales

01
Captura de video

Observar la cancha mediante cámaras conectadas a la Raspberry Pi.

02
Detección de pelota y pique

Analizar la imagen y seguir el movimiento de la pelota.

03
Asistencia arbitral

Mostrar una sugerencia de IN, OUT o REVISAR.

Hardware y software

Raspberry Pi 4

Placa principal encargada de ejecutar el programa.

Raspberry Pi Camera Module V2

Cámaras oficiales utilizadas para capturar las imágenes.

Cables CSI, fuente y microSD

Elementos necesarios para conectar y alimentar el sistema.

Python

Lenguaje utilizado para desarrollar el programa.

Picamera2 y OpenCV

Herramientas para capturar y procesar imágenes.

Teachable Machine

Herramienta considerada para experimentar con inteligencia artificial.
